# 术语说明

本文解释 [新方案与对比实验.md](新方案与对比实验.md) 中用到的概念，并标出对应的代码位置。数值以默认场景为准：120 GHz（波长 λ = 2.5 mm），发射孔径 0.2 m，接收孔径 2.5 cm，障碍物宽约 8.5 cm、距发射端约 0.2 m，接收机距离约 0.36 m。

## 1. 阵元、相位与波束

### 1.1 阵元是什么

发射端不是一副大天线，而是一排小天线，每个小天线叫一个**阵元**。本项目的 0.2 m 孔径上排了 **160 个阵元**，间距半个波长（1.25 mm）。阵元位置见 `Channel.centers`（[channel.py:35-39](../nfbeam/channel.py)）。

```
发射孔径（0.2 m，160 个阵元，间距 λ/2 = 1.25 mm）
 ┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
 │1│2│3│ │ │ │ │ … │ │ │ │ │ │ │ │160
 └┬┴┬┴┬┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴┬┘
  φ1 φ2 φ3        ……             φ160    ← 每个阵元一个移相器（和一个功放）
```

所有阵元发的是**同一个信号**，区别只在于每个阵元可以单独调节：

- **相位** φₙ：信号的波峰提前或推后多少。相位差 2π 相当于路程差一个波长（2.5 mm）。
- **幅度** aₙ：发多大的功率。相控阵里通常每个阵元有自己的功放，幅度固定为满功率，只调相位。

单个阵元很小，几乎向所有方向均匀辐射，本身没有方向性。方向性来自许多阵元的**叠加**。

### 1.2 相位如何决定波束

空间任意一点收到的场，是 160 个阵元的贡献相加：

$$E(\text{点}) = \sum_{n=1}^{160} w_n\, h_n(\text{点}), \qquad w_n = a_n e^{j\varphi_n}$$

- $h_n$ 是第 n 个阵元单独发单位信号时，在这一点产生的场，由传播和障碍物决定，与我们怎么设波束无关。代码先把每个阵元传播一次，得到矩阵 `H`（[channel.py:52-57](../nfbeam/channel.py)）。
- $w_n$ 是我们能控制的阵元激励。把 160 个 $w_n$ 排成向量 $w$，**这个向量就是"波束"**。

所以"波束"不是某个阵元的属性，而是**全部阵元相位的一种组合**。换一组相位，空间里的干涉图样就变了：有的地方各路信号同相，相互加强；有的地方反相，相互抵消。设计波束，就是挑一组相位，让加强的地方正好落在接收机上。

接收功率可以写成二次型 $P = w^H G\, w$（`Channel.gram`，[channel.py:133-137](../nfbeam/channel.py)），其中 $G$ 只由信道决定。后面所有的设计算法，都是在"每个阵元功率固定"的约束下让这个二次型最大。

### 1.3 几种典型的相位分布

| 相位沿孔径的形状 | 产生的波束 | 代码 |
| --- | --- | --- |
| 全部相同 | 正前方的平面波 | — |
| 线性（等差） | 向一侧倾斜的波束，斜率决定角度 | — |
| 抵消到某点的路程差：$\varphi_n=-k\,d_n$，$d_n$ 是阵元到焦点的距离 | **聚焦波束**：所有信号同时到达焦点、同相叠加 | `focus_beam`、`point_focus` |
| 聚焦相位再加一个三次项 $\tfrac{(2\pi B)^3}{3}c_n^3$ | **Airy 波束**：能量沿弯曲轨迹传播，可以"绕"过障碍物边缘 | `airy_phase`（[design.py:21-25](../nfbeam/design.py)） |
| 每个阵元单独优化，没有固定形状 | **逐阵元纯相位**：让绕过障碍物两侧的能量在接收机处同相叠加 | `phase_only`（[design.py:58-75](../nfbeam/design.py)） |

Airy 波束的三个参数中，B 是弯曲程度，F 是焦距，θ 是倾角；B = 0 时它就退化为聚焦波束。逐阵元纯相位的迭代 $w \leftarrow e^{j\angle(Aw)}$ 可以这样理解：每一步，把每个阵元的相位调到"与其他阵元在接收机处的合场同相"，这样每一步的接收功率都不会下降。

### 1.4 为什么能做到"聚焦到一点"和"绕过障碍物"

- **近场**：远场的分界距离约为 $2D^2/\lambda = 2\times0.2^2/0.0025 = 32$ m。接收机只在 0.36 m 处，处于很深的近场。在近场里，各阵元到接收机的距离差明显不同，波前是弯曲的，所以不仅能控制方向，还能控制"聚焦在多远"。远场里只能控制方向。
- **绕射**：障碍物挡住了直线路径，但电磁波会在障碍物边缘绕射。调相位可以让从障碍物两侧绕过去的能量在接收机处同相叠加，这就是遮挡下波束整形的收益来源。

### 1.5 阵元数和间距的作用

| 因素 | 影响 |
| --- | --- |
| 阵元数（孔径不变） | 间距必须 ≤ λ/2，否则会在其他方向出现与主瓣一样强的"栅瓣"，浪费能量。160 = 0.2 m ÷ 1.25 mm 是不出栅瓣的最少阵元数。 |
| 孔径宽度 | 孔径越宽，能聚焦得越紧，绕过障碍物的"视角"也越多。E8 表明孔径与障碍物相当时整形收益最大，约为障碍物的 3 倍时深遮挡基本消失。 |
| 每阵元一个功放 | 每个阵元的发射功率有上限，所以只能调相位，不能把功率集中到少数阵元。这就是"物理上界"达不到的原因。 |
| 移相器精度 | 实际移相器只能取有限个相位。2 bit 只能取 0°、90°、180°、270° 四个值（`quantize`，[design.py:37-41](../nfbeam/design.py)），E1 中 2 bit 量化让提升从 +202% 降到 +153%。 |
| 阵元误差 | 真实硬件的相位和幅度有误差。E6 的数字孪生里加入了 10° 随机相位误差和 1 dB 幅度误差，需要校准来补偿。 |

阵元数还决定计算量：完整设计的特征分解随阵元数大致按三次方增长，热启动只按线性增长（E9）。

## 2. 链路指标

### 2.1 频谱效率

每秒、每赫兹带宽能传多少比特，单位 bit/s/Hz。带宽固定时它与数据速率成正比：1 GHz 带宽、频谱效率 1.4，相当于 1.4 Gbit/s。

报告里用的是**有效频谱效率**（[link.py:269-273](../nfbeam/link.py)）：

```python
frac = (FRAME_S - overhead) / FRAME_S          # 一帧中用于传数据的时间比例
se   = frac * log2(1 + power / data_noise)     # 香农公式 × 时间比例
```

- **`log2(1 + SNR)`**：香农容量。波束越好，接收功率越大，这一项越大。
- **`frac`**：扣除开销。一帧 20 ms，固定有 0.1 ms 参考符号和 0.1 ms 反馈，所以最多 99%。这一帧再做 9 束扫描（每束 0.1 ms），就降到约 94.5%。频繁扫描会直接拉低效率。
- **噪声**：在 x = 9.5 cm（轨迹边缘）用聚焦波束时，信噪比定为 10 dB（[link.py:95-99](../nfbeam/link.py)）。所有策略共用同一个噪声。

| 频谱效率 | 对应信噪比（frac 取 0.99） | 说明 |
| --- | --- | --- |
| 1.0 | ≈ 0 dB | "可用"门槛，低于它算低速率帧 |
| 1.18 | ≈ 1.1 dB | 原方案深遮挡 |
| 1.41 | ≈ 2.3 dB | 新方案深遮挡，比原方案多约 1.2 dB 接收功率 |
| 3.12 | ≈ 9.3 dB | 新方案非遮挡区 |

**局限**：这是理想 AWGN 信道下的香农公式，不是真实调制编码测得的吞吐量或误码率，只适合横向比较策略。

### 2.2 失锁率与最长失锁

**失锁帧**：位置估计误差超过 **10 mm** 的帧（[metrics.py:22-23](../nfbeam/metrics.py)，门限 `LOCK_ERROR_M`）。失锁率是失锁帧所占的比例。

- **为什么是 10 mm**：接收孔径只有 2.5 cm，波束能量集中区域也是厘米量级。位置偏 1 cm，波束就是按错误的位置设计的，接收功率会大幅下降。
- 这是**评估用指标**，需要真实位置才能算，系统运行时自己并不知道是否失锁。
- **最长失锁**：一条轨迹里连续失锁的最长帧数 × 20 ms，再对轨迹取平均。它反映跟丢后多久能找回来。
- 失锁率和频谱效率不一一对应。E10 金属 TE 下失锁 24%，效率却最高，因为 TE 下阴影区能量本来就多。

### 2.3 其他链路指标

| 指标 | 含义 |
| --- | --- |
| 低于 1 bit/s/Hz 的帧 | 信噪比低于约 0 dB 的帧所占比例，代表链路基本不可用的时间 |
| 位置平均误差 / P95 | 位置估计误差的均值和 95% 分位 |
| 扫描帧 | 后验标准差超过 5 mm、额外做了 9 束补扫的帧所占比例。越低，开销越小 |
| 专用照射帧（E4） | 非协作模式下专门为定位发照射波束的帧。用数据波形回波时，大部分帧不需要额外照射 |
| 相对聚焦提升 | 同一位置上，某波束的接收功率相对聚焦波束的变化 |
| 遮挡损耗 | 接收功率相对"同一位置、无障碍物、聚焦波束"的 dB 值，越负越严重 |
| 链路余量（E7） | 要让 90% 的位置达到 1 bit/s/Hz，还需要提高多少 dB 的信噪比 |

## 3. 统计方法

| 概念 | 解释 |
| --- | --- |
| 深遮挡 | 从发射孔径到接收机的几何射线中，≥ 80% 被障碍物挡住的位置（`blockage_ratio ≥ activation_bl = 0.8`）。报告里大部分数字只统计这些帧，因为不遮挡时聚焦波束就够了 |
| 未见场景 | 旧方案训练网络时没用过的 16 个几何场景，新旧方案都在这些场景上比较 |
| 配对比较 | 所有策略在同一次运行里共用相同的轨迹、噪声、增益起伏和丢包样本，差别只来自策略本身 |
| 95% 区间 | 以场景为单位有放回重采样，重算相对变化，取 2.5%–97.5% 分位。区间整个在 0 以上，说明提升不是偶然的 |
| 5% 分位 / 最差点 | 按结果从差到好排序，取第 5% 处和最差的值，衡量尾部风险。旧方案平均 +56%，但 5% 分位是 −75% |
| dB 中位数（E8） | 聚焦功率接近 0 时，百分比提升会大到上万，平均值失去意义，所以改取 dB 中位数 |

例：E3 基准行"新方案 1.41（+20.9% [15.9, 26.3]），失锁 2.0%，扫描帧 1.6%"的意思是：深遮挡帧的平均有效频谱效率是 1.41 bit/s/Hz，比原方案高 20.9%，95% 区间不含 0；只有 2% 的帧位置误差超过 1 cm；只有 1.6% 的帧花时间补扫。

## 4. 波束与对照策略

| 名称 | 解释 |
| --- | --- |
| 聚焦波束 | 所有阵元的信号同相到达接收点，相当于"直接瞄准"。是所有比较的基准 |
| Airy 波束 | 只有 (B, F, θ) 三个参数的弯曲波束族，旧方案和参考论文使用 |
| 在线 Airy 优化 | 在线搜索 (B, F, θ)，适用于只能生成 Airy 波束的硬件 |
| 逐阵元纯相位 | 160 个相位各自优化、幅度固定。自由度最多，相控阵下效果最好 |
| 物理上界 / 幅相上界 | 幅度和相位都可任意调、只限总功率时的最优值，相控阵做不到，只作天花板参照 |
| 码本波束训练 | 每帧把预先准备的 17 个波束都试一遍，用最强的一个，代价是每帧都扫描 |
| 新跟踪 + 聚焦 | 新跟踪器配聚焦波束，用来区分"跟踪"和"波束设计"各自的贡献 |
| 真实位置参照 | 已知真实位置和几何的最优纯相位，不计感知开销，现实中达不到 |

## 5. 跟踪与感知

| 概念 | 解释 |
| --- | --- |
| 协作 / 非协作 | 协作：接收机测量导频并反馈。非协作：接收机不配合，发射端只靠回波定位（E4） |
| 导频 / 参考符号 | 每帧开头 0.1 ms 的已知信号，接收机用它测信道，也用于定位。接收孔径分成 4 个子孔径分别测幅度 |
| 网格贝叶斯滤波 | 把"位置 × 速度"划成网格，每格存一个概率（后验）。每帧按运动模型推移，再乘上测量的似然更新。允许多个峰并存，不需要"检测到 / 没检测到"的硬判决 |
| 似然 | 在每个候选位置下，出现当前测量值的可能性有多大 |
| 补扫 / 重捕获 | 后验标准差超过 5 mm 时额外发 9 个波束重新定位 |
| 反馈时延与丢包 | 测量结果过几帧才到，或丢失。时延感知的做法是把迟到的测量放回它对应的那一帧，从当时存档的先验重新滤波 |
| Gilbert–Elliott 突发丢包 | 两状态丢包模型，"坏"状态下大量丢，丢包成串出现。本项目约 11% 的帧处于坏状态，平均每段 4 帧 |
| 距离门 | 按回波往返时延区分不同距离的反射，只保留目标所在距离单元。4 GHz 带宽对应距离分辨率 c/(2B) ≈ 3.75 cm，其他距离上的回波用 Hann 窗的距离响应衰减，下限 −40 dB（[sensing.py:101-122](../nfbeam/sensing.py)）。E4 中对准接收机，压低障碍物回波和收发泄漏；E11 中对准障碍物 |
| 数据波形回波 | 直接用数据信号的回波定位，不另外占用时间。数据持续时间长，匹配滤波后噪声更低 |
| 收发泄漏 | 发射信号直接漏进自己的接收机，时延约为 0 |

距离门在代码中是理想化模型：每种干扰只乘一个标量衰减系数，没有仿真真实宽带波形。如果实际带宽窄得多，障碍物和接收机可能落在同一距离单元里，距离门就基本失效。

## 6. 几何与模型

| 概念 | 解释 |
| --- | --- |
| 几何失配 / 强失配 | 系统以为的障碍物几何与真实几何不同。失配：横移 ±4 mm、宽度 ±6%；强失配再加纵向 ±5 mm、厚度 ±15% |
| 几何假设与权重 | 在标称几何周围放 3 × 3 个候选，每个带权重，按测量更新。波束按加权平均设计，这就是稳健设计 |
| 角谱模型 | E1–E9 用的快速传播模型，把障碍物当一层层吸收掩膜，没有反射，绕射是近似的 |
| 全波解（E10） | 直接解二维亥姆霍兹方程的精确解，含反射、绕射和极化，用来充当"真实信道" |
| TM / TE | 电场垂直于传播平面（TM）或磁场垂直于传播平面（TE）。TE 下金属边缘绕射更强，阴影区能量更多 |
| 电尺寸 D/λ | 孔径宽度是波长的多少倍，本项目为 80 |
| z/D | 接收距离与孔径宽度之比，衡量有多近场。本项目约为 2，文献多在 5–15 |
| CRB（克拉美–罗下界） | 给定模型和噪声下，无偏估计器的最小可能误差。误差接近 CRB 说明估计器接近理论最优 |
| 接受检验（E11） | 回波峰值信噪比 ≥ 15 dB 且未解释回波能量 ≤ 10% 才接受几何估计，否则退回先验，避免错误估计让结果比不估计还差 |
| 热启动（E9） | 从上一帧的波束出发迭代 5 步，而不是每帧从零优化。接收机每帧只移动零点几毫米，几步就够 |
| 现场建表（E9） | 几何估计出来后，为当前场景在 1 mm 网格上算一张波束表，作为额外的初值 |
| 数字孪生（E6） | 带隐藏几何偏差、阵元误差和 3 bit 移相器的"假硬件"，用来检验校准流程，不是实测 |
