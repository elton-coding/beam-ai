# 实测对照与模型校准：数据格式与操作流程

这份文档对应建模文档第 5 节的第 3 项缺口。**目前项目里没有实测的信道、回波或设备时序数据。** `nfbeam` 已经备好测量数据格式、读取函数、模型校准和对照流程，并用一个数字孪生生成的合成数据跑通了整条流程（实验 E6）。合成数据不能当作实测结论；实测数据到手后，按本文流程替换数据源即可。

## 1. 测量活动

| 项目 | 建议设置 | 说明 |
| --- | --- | --- |
| 接收机位置 | 每个几何场景 40 个已知横向位置，覆盖 −0.10 至 +0.10 m | 用导轨或定位系统记录真值。深遮挡和其他位置都要有 |
| 探测波束 | 9 个绕射波束和 9 个聚焦波束，共 18 个 | 在 `nfbeam.link.SCAN_X` 的位置上，用名义模型设计 |
| 接收读数 | 每个子孔径（共 4 个）的导频幅度，每次读数平均 16 个导频 | 同时记录同一时段的噪声底 |
| 几何真值 | 障碍物中心、宽度、厚度、纵向位置的实测值 | 只用于评价校准效果，不参与拟合 |
| 吞吐量 | 用设计波束发数据，记录有效速率 | 用来对照"仿真预测的有效频谱效率"与"实测值" |

## 2. 文件格式

每个场景一个目录，内含两个 CSV 文件。读取函数 `nfbeam.calibration.load_measurements(目录)` 会检查列名。

**`pilot_amplitudes.csv`**：每行一个读数。

| 列 | 单位 | 含义 |
| --- | --- | --- |
| `rx_x_m` | m | 接收孔径中心的横向位置 |
| `beam_id` | — | 对应 `beams.csv` 里的波束 |
| `subaperture` | 0–3 | 接收子孔径编号，从 −x 侧开始 |
| `amplitude` | 归一化幅度 | 相关后的导频幅度，与仿真的单位发射功率归一化一致 |
| `noise_power` | 归一化功率 | 该读数的复噪声功率（平均后） |

**`beams.csv`**：每行一个阵元的指令相位。

| 列 | 单位 | 含义 |
| --- | --- | --- |
| `beam_id` | — | 波束编号 |
| `element` | 0–159 | 阵元编号，从 −x 侧开始 |
| `phase_rad` | rad | 下发给移相器的相位，量化前的值 |

示例目录：`nfbeam/results/e6/synthetic_campaign_scene64/`（合成数据）。

## 3. 校准模型

`nfbeam.calibration.fit` 按极大似然拟合以下参数：

- **障碍物几何偏差**：中心横移、宽度比例、纵向位置、厚度比例；
- **阵元相位误差的平滑部分**：5 阶 Legendre 多项式；
- **整体增益**。

拟合分两步：先在横移和宽度的粗网格上搜索，再交替细化相位系数（最小二乘）和几何参数（Nelder–Mead）。逐阵元的随机误差不可辨识，会留在残差里。

## 4. 对照指标

拟合与评价按位置**交叉验证**：一半位置用来校准，另一半用来评价。所有指标都按建模文档的分组口径，分别给出深遮挡、其他位置和全部位置。

1. **功率预测误差**：预测功率与测量功率之比的 dB 值，报告偏差、RMSE 和 90% 分位绝对误差。名义模型和校准后模型分别报告。
2. **几何恢复误差**：估计的几何偏差与实测几何真值之差。
3. **波束效果**：在实测链路上比较四种波束的接收功率和有效频谱效率：
   - 聚焦波束；
   - 用名义模型设计的波束；
   - 用校准后模型设计的波束；
   - 硬件误差完全已知时设计的波束（只有数字孪生能给出）。
4. **仿真与实测的有效频谱效率差**：每种波束都算"预测值 − 实测值"的偏差和 RMSE。

## 5. 换成实测数据的步骤

1. 按第 2 节的格式整理数据，每个场景一个目录。
2. 在 `nfbeam/experiments/e6_calibration.py` 里，把 `DigitalTwin` 生成数据的 `campaign` 换成 `load_measurements`，并把波束评分改成读取实测吞吐量。
3. 运行实验，结果写入 `nfbeam/results/e6/`。报告结论时注明数据来源和测量条件。
