# 120 GHz 近场遮挡通信：项目系统建模、研究问题与对比实验

## 1. 项目要解决的问题

本项目研究移动接收机在近场通信中经过障碍物后方时，系统能否把足够的能量送到接收机，并在位置有时延、位置难以获取、探测占用通信资源的条件下维持链路。

研究从**真实位置已知时的波束传播**开始，逐步加入**位置时延、反射测位、探测开销和场景变化**，最后考察**在传输数据的同时利用通信信号获取位置**。每个阶段对应不同的系统输入条件，定位和通信性能应在各自的条件下比较。

## 2. 共用系统模型

| 要素 | 建模设定 |
| --- | --- |
| 场景与运动 | 在二维 \(x\)-\(z\) 截面内，包含一个发射孔径、一个具有宽度和厚度的矩形障碍物、一个接收孔径。每个场景内接收机沿横向移动，纵向距离已知。跨场景改变障碍物的位置、宽度、厚度以及接收机的纵向距离。 |
| 传播与接收功率 | 用标量角谱描述 120 GHz 近场传播。通信传播模型中的障碍物视为吸收体，接收功率由接收孔径内场强平方积分得到。反射测位另用回波观测模型描述目标反射、障碍物回波和噪声。 |
| 遮挡范围 | 从发射孔径各点向接收机中心作直线，以被障碍物挡住的比例定义几何遮挡率。达到 80% 的位置归为深遮挡。评价用真实几何分组，分别汇报深遮挡、其他位置和全程。 |
| 系统可用信息 | 各阶段分别提供当前真实坐标、真实历史坐标、专用探测观测或正常通信帧的观测。在需要测位的实验中，真实轨迹用于生成观测和评价。几何失配实验允许真实场景与系统使用的名义场景不同。 |
| 时间与资源 | 动态通信按帧评价。早期实验用接收功率刻画波束性能。引入探测资源后，按相应协议扣除探测、校准和反馈占用的时间。最新融合仿真每帧 20 ms，通信参考符号与反馈各预留 0.10 ms，独立扫描另占时间。 |

相关文件：[传播与几何模型](../direct_network/core/physics.py)、[通信帧仿真设定](通信导频复用与按需补扫实验.md)。

## 3. 分阶段建模、研究问题与对照实验

### 3.1 已知真实位置的静态遮挡通信

**建模。** 已知障碍物几何和接收机当前真实位置。以一组静态测试点覆盖接收机穿越障碍物后方的过程，每个位置各自评价。这一阶段直接给出位置，考察不同发射波前产生的接收功率。

**问题。** 位置完全准确时，深遮挡下能否把能量送到接收机？波束本身提供多大增益？在相同约束下，还有多少可见的改善空间？

**对比实验。** 统一发射功率，比较常规聚焦与 Airy 波束。在完整穿越路径和密集深遮挡测试点上分别评估。绘制标出接收孔径的传播热力图，对照同约束下的离线可行参照和归一化功率理论上界，并检查传播网格及障碍物积分步长对结果的影响。

### 3.2 位置真实但有时延的移动通信

**建模。** 接收机连续移动，发射端只能使用过去帧的真实位置。历史坐标无测量噪声和失检，当前坐标与过去坐标之间的偏差来自运动与时间差。

**问题。** 单独的位置时延会带来多大位置误差和通信损失？接收机速度变化时，过期坐标会怎样影响接收功率？

**对比实验。** 固定传播几何和波束设计条件，比较当前真实位置、上一帧位置和根据历史得到的当前估计。用同一帧的真实接收机位置计算三组接收功率，同时报告位置误差。

### 3.3 位置未知的被动反射测位

**建模。** 发射端照射场景并接收反射回波。接收机回波经过双程传播并叠加噪声，部分帧无位置测量。连续失检期间，系统只能使用之前获得的轨迹信息。

**问题。** 遮挡削弱回波后，接收机是否仍可检出？测位误差和连续失检会给通信造成多大影响？

**对比实验。** 分别比较深遮挡与其他位置、不同运动形式、不同回波噪声。设真实位置作为参照，对比反射估计得到的位置与失检时保持最近一次观测，报告位置误差、连续失检时长和接收功率。

### 3.4 接收机可配合或不可配合，且探测占用资源

**建模。** 可配合时，接收机发送已知导频，系统观察单程响应。不可配合时，发射端观察双程回波。回波进一步包含目标反射强度变化、障碍物杂波、背景漂移和附加路径。专用扫描和背景校准需要计入资源消耗。

**问题。** 两种硬件条件下，能获得怎样的定位可靠性和有效通信性能？多扫几束、延长导频或提高导频强度是否划算？杂波和校准误差会在什么条件下导致虚警或失检？

**对比实验。** 比较主动导频与被动回波、不同扫描束数、单束时长、参考信噪比和导频强度。分别改变目标反射、障碍物回波与附加路径，分析各因素影响。考察无背景校准、校准过期、观测几何失配、误警门限以及扫描资源配置。比较定位误差尾部、连续失检和低速率帧比例。

### 3.5 未见几何场景下的性能推广

**建模。** 由一个固定几何扩展到 **80 个场景、2,400 个位置样本**，按场景划分数据，留出 **16 个未见场景**。在新场景中分别评价已知真实位置的波束性能，以及需要先估计位置的端到端性能。

**问题。** 固定场景中的增益能否推广到新几何？平均值提高时，是否仍有部分场景或位置严重退化？退化主要来自位置估计还是波束本身？

**对比实验。** 在留出场景的有标签位置和额外位置上，比较接收功率、胜过聚焦的比例、功率增益低分位以及与离线可行参照的差距。在连续运动轨迹上评估端到端通信。同一位置估计下比较不同波束，同一波束设计条件下比较真实位置与估计位置。

### 3.6 通信与位置获取共用信号

**建模。** 接收机可配合时，正常通信帧中的参考符号同时提供信道观测。已完成的仿真使用四路接收子孔径响应，并为反馈预留时隙。当帧通信观测在反馈到达后才能影响后续波束。参考符号、反馈和额外扫描均占用资源。

**问题。** 边传数据边获取位置，节省的扫描时间能否抵消定位误差带来的通信损失？深遮挡、导频噪声升高或几何失配时，收益是否仍能保持？

**对比实验。** 在同一帧长、带宽与发射能量预算下，比较每帧独立扫描、定期扫描、首帧扫描后仅使用正常通信参考信号、以及允许额外补扫这四种条件。对比扫描占比、位置误差、最长无可靠更新时长、有效频谱效率和低速率帧比例。分别测试基准条件、几何失配和导频噪声增大。

## 4. 评价指标与对照规则

| 要验证的能力 | 主要指标与对照 |
| --- | --- |
| 波束传播 | 接收功率、相对聚焦的逐点百分比提升、胜率和低分位表现。离线可行参照给出在相同波束约束下已达到的性能。理论上界给出物理限制。 |
| 位置获取 | 位置平均绝对误差、绝对误差第 95 百分位、检出率、误警率、最长连续无可靠更新时长。连续轨迹误差要覆盖失检帧。 |
| 端到端通信 | 有效频谱效率、低于指定速率门限的帧比例，以及探测和反馈开销。比较时保持场景和轨迹一致，并按帧长、带宽和发射能量统一资源预算。 |

每帧的有效频谱效率按通信载荷时间折算：

$$
R_{\mathrm{eff},t}
=\frac{T_{\mathrm{data},t}}{T_{\mathrm{frame}}}
\log_2\!\left(1+\frac{P_{\mathrm{rx},t}}{P_{\mathrm{noise}}}\right).
$$

其中，$T_{\mathrm{data},t}$ 是扣除该实验所计开销后实际用于载荷的时间。已知位置对照刻画给定波束设计条件下的理想位置输入，离线可行参照和理论功率上界各自回答波束性能的不同问题。所有主要指标分别给出**全程、深遮挡和其他位置**的结果。

## 5. 仍需要补齐的对比实验

1. **接收机不可配合时的同波形感知。** 在相同发射资源下，比较专用照射和承载数据波形的回波定位。关注双程回波强度、障碍物虚警、连续失检时长和端到端有效频谱效率。
2. **反馈延迟和丢包。** 现有通信帧复用仿真假设反馈在预留时隙内到达。加入多帧时延、随机丢包和连续丢包，比较失锁时长、重捕获开销和深遮挡中断。
3. **实测与仿真对照。** 用实际信道、回波和设备时序校准模型。沿用相同的遮挡分组、发射与时间预算，对比实测定位误差、接收功率和有效吞吐量。当前传播、定位和有效频谱效率结论来自仿真。
